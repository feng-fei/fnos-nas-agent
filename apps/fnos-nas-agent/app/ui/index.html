首次授权 / 连接配置指南

            
只生成命令，不接收验证码或令牌。

          
          

            
当前版本不会把 OAuth 验证码通过网页转发，也不会收集密码或令牌。请在 NAS 终端中运行官方 CLI 登录，完成后回到这里检测连接。

            

              
              
            

            

              
              
            

            

              
              
              
HTTPS 常见端口：直接连接 IP 通常是 5667，域名通常是 443；请以 NAS 的实际 CLI/API 配置为准。HTTP 仅建议用于可信局域网。

            

            

              
              
            

            

              
            

            
            
填写 NAS 地址后生成命令。

            
            
    
              
  1. 先审核并安装官方 fnOS Skill 中的 CLI，并启用该 Skill。
    2. 
              
  2. 通过 fnOS 终端或可信 SSH 登录 NAS，再粘贴执行生成的命令。命令会切换到 Agent 的运行账户，并把 OAuth profile 放在 Agent 私有数据目录中，确保 Agent 后续能读取它。
    3. 
              
  3. CLI 输出授权链接后，在你自己的浏览器中登录并确认授权，再将一次性 code 直接粘贴到 CLI 的交互提示符。
    4. 
              
  4. CLI 显示登录成功后，回到本页面点击“检测官方 CLI 连接”。
    5. 
            

            
本页面只生成命令，不会执行登录，不会接收验证码或令牌。切勿把验证码、access token、refresh token 或完整调试输出发送给助手。命令使用 sudo 切换运行账户；若 NAS 没有 sudo，请先切换至 Agent 服务账户，再删除命令开头的 sudo -u … -- 前缀，不能改用其他账户保存 profile。

从 GitHub 导入

            
下载内容只进入隔离审核区，不会执行。

          

          

            

              

                
                
              

              

                
                
              

              

                
                
              

              
              
可直接粘贴仓库地址（自动识别默认分支），也可粘贴分支/标签 ZIP；下载内容只进入隔离审核区，不会执行。

            

            

              

                
                
              

              

                
                
              

              
              
按行顺序导入；所有项目共享 25 MiB 累计下载上限。单项失败不会撤销已成功的隔离导入。

安全说明

        
边界写清楚，比事后追责更重要。

      

      

        

          

            
任意系统命令和导入 Skill 执行默认关闭。已登记的常规文件操作需通过有效会话及参数校验。HTTP 不加密传输内容，因此仅限可信局域网，不要暴露到公网。

            
    
              
  • 破坏性动作（删除）必须经过服务端审批，授权与会话绑定，浏览器无法自行伪造确认。
    • 
              
  • 全局只读模式与停机开关会阻断全部变更型调用，可在概览页或 /api/execution-mode 切换。
    • 
              
  • 首启设置管理密码时，非本机请求还必须提供设备安装码。

首次安全设置

    
首次使用请设置管理密码（至少 10 个字符）。以后只需输入密码即可登录。

  

  

    
首次设置期间，页面可由可信局域网访问。当前版本不执行任意系统命令，也不会运行导入的 Skill。请勿将端口转发到公网或在不可信网络中设置。

    

      

        
        
      

      

        
        
        
服务端启用安装码保护时必须填写；安装码打印在 NAS 终端的首次启动日志中。

      

      
    

    

  






  

    
登录验证

    
输入管理密码登录。密码不会保存在浏览器本地存储中。

  

  

    

      

        
        
      

      

        
        
仅在个人可信设备上勾选；共享设备请勿勾选。
