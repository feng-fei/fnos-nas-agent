首次授权 / 连接配置指南

当前版本不会把 OAuth 验证码通过网页转发，也不会收集密码或令牌。请在 NAS 终端中运行官方 CLI 登录，完成后回到这里检测连接。





HTTPS 常见端口：直接连接 IP 通常是 5667，域名通常是 443；请以 NAS 的实际 CLI/API 配置为准。HTTP 仅建议用于可信局域网。





填写 NAS 地址后生成命令。



  1. 先审核并安装官方 fnOS Skill 中的 CLI，并启用该 Skill。
  2. 通过 fnOS 终端或可信 SSH 登录 NAS，再粘贴执行生成的命令。命令会切换到 Agent 的运行账户，并把 OAuth profile 放在 Agent 私有数据目录中，确保 Agent 后续能读取它。
  3. CLI 输出授权链接后，在你自己的浏览器中登录并确认授权，再将一次性 code 直接粘贴到 CLI 的交互提示符。
  4. CLI 显示登录成功后，回到本页面点击“检测官方 CLI 连接”。


本页面只生成命令，不会执行登录，不会接收验证码或令牌。切勿把验证码、access token、refresh token 或完整调试输出发送给助手。命令使用 sudo 切换运行账户；若 NAS 没有 sudo，请先切换至 Agent 服务账户，再删除命令开头的 sudo -u … -- 前缀，不能改用其他账户保存 profile。
