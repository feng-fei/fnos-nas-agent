# Phase 68 — Gemini and Groq presets

Adds quick-start presets for Google Gemini's OpenAI-compatible Chat Completions API and Groq's OpenAI-compatible endpoint.

- Presets contain public endpoint metadata and official documentation links only.
- Users must supply their own API key and choose a model ID enabled for their account.
- Existing HTTPS endpoint validation, connection testing, catalog discovery and bounded request handling remain authoritative.
- No model is enabled or selected automatically by adding a preset.
